The first release of Orbit: start and control Moonlight streams from your Sunshine host.

**Early preview.** Orbit is used daily on one setup: KDE Plasma on the host and a Raspberry Pi 5 on a text console.
The display features (resolution matching, window placement, monitor power) need KDE Plasma. The Windows agent has
only been tested in a VM, and the host doesn't run on Windows yet.

## Files

| File | For |
|---|---|
| `orbit-host-0.1.0-linux-x64.zip` | The host, on the Sunshine machine (Linux, x64), with its own Java runtime |
| `orbit-agent-0.1.0-linux-arm64.zip` | The agent on a Raspberry Pi or other ARM64 Linux client, with a Java runtime |
| `orbit-agent-0.1.0-linux-x64.zip` | The agent on an x64 Linux client, with a Java runtime |
| `orbit-agent-0.1.0-windows-x64.zip` | The agent on Windows 10/11, with a Java runtime |
| `orbit-agent-0.1.0.zip` | The agent for clients that have Java 25 already |
| `SHA256SUMS` | Checksums: `sha256sum -c SHA256SUMS` |

## Install

- **Host:** unzip, then run `./orbit-host/install-host.sh` in your desktop session. Enter Sunshine's login under
  ☰ ▸ Settings ▸ Sunshine.
- **Linux client with a desktop:** unzip, then `./orbit-agent/install-agent.sh`.
- **Linux client on a text console** (e.g. a Pi without a desktop): unzip, then `./orbit-agent/install-agent-tty1.sh`,
  and reboot.
- **Windows client:** unzip, then `powershell -ExecutionPolicy Bypass -File install-agent.ps1` in the folder.

Then approve and pair the client in Orbit's window. See the README for the details.
